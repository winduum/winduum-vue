# [Switch](https://winduum.dev/docs/components/switch.html)

## Installation
By default, we recommend copying and pasting the code from this directory to your project and remapping the imports to local.

```js
import { Switch } from '@/components/ui/switch'
```
### NPM
Alternatively, you can also import directly from `npm` so you can leverage updates.
```shell
npm i winduum-vue
```

```js
import { Switch } from 'winduum-vue/src/components/switch'
```

### Docs
Visit [docs](https://winduum.dev/docs/components/switch.html) to learn more and see usage examples.
