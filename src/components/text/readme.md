# [Text](https://winduum.dev/docs/components/text.html)

## Installation
By default, we recommend copying and pasting the code from this directory to your project and remapping the imports to local.

```js
import { Text } from '@/components/ui/text'
```
### NPM
Alternatively, you can also import directly from `npm` so you can leverage updates.
```shell
npm i winduum-vue
```

```js
import { Text } from 'winduum-vue/src/components/text'
```

### Docs
Visit [docs](https://winduum.dev/docs/components/text.html) to learn more and see usage examples.
